# NPC Chaos

NPC Chaos is a chaotic NPC behavior configuration pack for FiveM servers.  
It combines multiple public scripts, tweaks, and configuration changes to create unpredictable civilian and police interactions.

This project is NOT a fully original script. It is a compilation of existing resources configured together to produce chaotic NPC behavior.

The goal is simple: make NPCs completely unpredictable and sometimes absolutely ridiculous.

## Features

- Aggressive and unpredictable NPC reactions
- Random hostile civilians
- Overreactive police responses
- NPCs that escalate situations quickly
- Chaotic interactions that can break normal roleplay expectations
- Funny and sometimes completely broken encounters

This pack is mainly meant for testing, messing around, or creating chaotic moments on a server.

## Why This Exists

This repository was created to experiment with NPC behavior and see what happens when multiple NPC related scripts interact with each other.

Sometimes the results are hilarious.  
Sometimes they are completely unhinged.

Either way, it creates chaos.

## Installation

1. Download or clone this repository

git clone https://github.com/YOURUSERNAME/npc-chaos

2. Place the resources into your FiveM server `resources` folder

3. Ensure the resource in your server.cfg

ensure npc-chaos

4. Restart your server

## Disclaimer
